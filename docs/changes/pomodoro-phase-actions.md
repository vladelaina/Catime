# 番茄钟阶段动作变更说明

状态：未发布。范围：本次番茄钟工作状态颜色变化及配套的阶段动作配置。

## 功能变化

- 新增工作中、短休息、长休息三个阶段的动作配置，进入相应阶段时执行。
- 托盘菜单中的“状态动作配置”与“组合”同级，紧接在“组合”下方；其中按阶段配置“颜色”和“声音”，可分别勾选。
- 三个阶段默认只启用颜色动作。工作中使用当前默认颜色，短休息使用浅青到浅蓝渐变，长休息使用青绿到亮绿渐变。
- 三个阶段的默认音源统一设为系统提示音（`SYSTEM_BEEP`）；勾选“声音”即可在进入该阶段时播放。
- 新增独立的 `pomodoro_hooks.ini`，与主 `config.ini` 放在同一目录，按阶段定义颜色和声音文件。

| 阶段 | 配置节 | 默认颜色 |
| --- | --- | --- |
| 工作中 | `[Work]` | `DEFAULT`，跟随当前默认颜色 |
| 短休息 | `[ShortBreak]` | `#89F7FE_#66A6FF`，浅青 → 浅蓝 |
| 长休息 | `[LongBreak]` | `#10BD92_#8CE442`，青绿 → 亮绿 |

## 配置与兼容性

主配置 `[Pomodoro]` 中新增以下三个键，分别保存每个阶段启用的动作；默认值均为 `COLOR`：

```ini
[Pomodoro]
POMODORO_WORK_ACTIONS=COLOR
POMODORO_SHORT_BREAK_ACTIONS=COLOR
POMODORO_LONG_BREAK_ACTIONS=COLOR
```

`pomodoro_hooks.ini` 的三个阶段节分别包含 `Color` 和 `SoundFile`。首次执行颜色或声音动作时，如果文件不存在，会创建默认配置；已有文件不会被覆盖。编辑后的设置在下一次进入对应阶段时读取。

- 支持的动作仅有 `COLOR` 和 `SOUND`；动作名称不区分大小写，支持逗号或 `|` 分隔、首尾空白和重复项去重。
- 旧主配置缺少动作键时，首次取消默认颜色也会写入空动作列表，重启后保持关闭。
- 新增动作菜单和帮助内容覆盖仓库支持的全部 10 种语言。
- 旧的 `COLOR_DEFAULT`、`COLOR_LIGHT_GREEN`、`COLOR_GREEN` 均兼容转换为 `COLOR`，具体颜色由阶段配置决定。
- 删除 `LOG` 动作的执行代码、注册项和中英文帮助说明；旧配置中的 `LOG` 被忽略。程序内部的阶段切换、配置错误等诊断日志继续保留。
- `SHAKE` 及其他不支持的动作被忽略。只有被移除动作的配置会变成空动作列表；需要颜色或声音时，应重新勾选对应动作。
- 已有 `pomodoro_hooks.ini` 中的颜色和声音设置继续保留；升级后希望使用新渐变色，可按上表修改相应的 `Color` 值。
- 旧声音配置 `DEFAULT` 继续使用当前通知音；通知音为空时回退到系统提示音，避免勾选后没有音源。显式留空的 `SoundFile` 仍表示静音；缺失或无法读取的声音配置使用系统提示音。

## 行为调整

- 阶段颜色只覆盖当前显示，不改写用户的默认时钟颜色；重置或结束番茄钟时清除覆盖并恢复默认颜色。
- 色板预览优先于阶段颜色；预览结束后回到当前阶段颜色。
- 开始、重新开始番茄钟，以及进入下一个时间段时执行对应阶段的动作；即使阶段类型相同，也会执行新一次的进入动作。
- 阶段切换声音由该阶段的 `SOUND` 动作控制，避免与原先的切换播放逻辑重复发声。全部番茄钟循环完成后的提示音仍按原有通知设置播放。
- 将动作注册、颜色显示覆盖和阶段配置读取分开；阶段钩子定义配置文件路径，显示时使用已读取的颜色，避免每次绘制都访问配置文件。
